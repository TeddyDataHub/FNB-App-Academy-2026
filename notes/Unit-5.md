# Unit 5 – Selection of Tasks

## Topic
Selection of Tasks

## What I Learned
- Making decisions using `if` statements.
- Using `elif` and `else`.
- Comparing values with comparison operators.
- Using logical operators such as `and`, `or`, and `not`.
- Writing programs that respond differently based on conditions.
- Creating simple decision-making applications.

## Reflection
This unit introduced decision-making in Python. I learned how to control the flow of a program using conditional statements. This allows programs to solve problems by responding to different situations and user input.
