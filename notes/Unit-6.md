# Unit 6 – Repeating Tasks

## Topic
Repeating Tasks

## What I Learned
- Why loops are useful in programming.
- Using `for` loops to repeat actions.
- Using `while` loops.

This unit showed me how to automate repetitive tasks using loops. I learned when to use `for` and `while` loops and how they improve program efficiency. These concepts are fundamental for solving larger programming problems and processing data.
