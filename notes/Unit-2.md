# Unit 2 – Manipulating Strings

## Topic
Manipulating Strings

## What I Learned
- What strings are in Python.
- How to create and store string values.
- How to combine strings using concatenation.
- How to access individual characters using indexing.
- Common string methods such as `upper()`, `lower()`, `strip()`, and `replace()`.
- How to format strings to produce readable output.

## Reflection
This unit helped me understand how Python handles text data. I learned several useful string methods that make it easier to clean and format text. These skills will be valuable when working with user input and preparing data for analysis.
